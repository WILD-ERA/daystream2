# Daystream

Go live on WhatsApp — West Africa.

## To run on Glitch

1. Go to glitch.com
2. Click New Project → Import from GitHub
   OR click New Project → glitch-hello-node
3. Delete all existing files
4. Upload these files exactly as they are
5. In the .env file change BASE_URL to your Glitch project URL
   (shown in the top left of your Glitch project — looks like https://your-project-name.glitch.me)
6. Glitch starts automatically

Your broadcaster is at: https://your-project-name.glitch.me
Your viewer link is:    https://your-project-name.glitch.me/watch/STREAM_ID
